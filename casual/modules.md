# 模块

与 Quests 集成以提供自定义目标、奖励和要求的插件，使用的是所谓的 **模块**。模块是由开发者使用 [Quests API](../master/custom-quest-api.md) 创建的 jar 文件，它充当 Quests 与集成插件之间的中介。这与 [依赖项](../beginner/dependencies.md) 不同，后者通常不需要模块。

模块 jar 文件必须放置在 _Quests/modules_ 文件夹中，而目标插件则像往常一样放置在 _/plugins_ 文件夹中。大多数模块完全是可选的，尽管有些模块会由其他插件自动安装。下面是一个不完整的流行插件列表，这些插件已知存在对应的模块，并附带集成方式的描述。

如果在这里或通过网络搜索找不到特定用途的模块，可以考虑在以下站点雇佣开发者：

* [Quests 社区](https://discordapp.com/invite/QdJAv2G7qg)
* [SpigotMC](https://www.spigotmc.org/forums/hiring-developers.55/)
* [Lectern](https://lectern.browsit.org/forum/view/6-services/)

Quests 及其贡献者对第三方模块的质量和/或功能不承担任何责任，无论来源如何。
